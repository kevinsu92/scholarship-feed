# scholarship-feed — 내 장학 마감표 공고 피드

**이 저장소는 피드 전용입니다.** 「내 장학 마감표」(웹 [jangmak.com](https://jangmak.com)·iOS 앱)가 받는 장학 공고 피드를 정적 파일로 내보내는 공개 통로이고, 코드는 비공개 저장소에 있습니다.

- 피드: <https://kevinsu92.github.io/scholarship-feed/v2/index.json> (목차) + 전국·시·도 묶음
- 파일은 `gh-pages` 가지에 있습니다. 수집기가 하루 세 번 공고를 모아 Ed25519로 서명한 뒤 그 가지를 통째로 새로 올립니다(이력 없이 덮어씀, 지난 회차 묶음은 한 번 더 남김). 웹과 앱은 서명을 확인한 피드만 씁니다.
- 공고는 각 기관이 공개한 원문에서 모읍니다(robots.txt 준수, 로그인·우회 없음). 남의 휴대폰 번호·개인 메일은 가려서 싣습니다. 지원 가능 여부의 최종 확인은 원문에서 해 주세요.
- 피드는 공고를 요약·구조화한 값과 짧은 근거 문장만 담고, 원문과 첨부는 출처 링크로 잇습니다. 삭제·정정 요청은 이 저장소의 이슈로 받습니다. 이슈는 공개 글이니 공고 id와 원문 주소만 적고 전화번호·메일은 다시 적지 마세요. 비공개 연락처는 준비 중입니다.
- 이 저장소에는 학생 정보가 없습니다. 학생의 프로필은 각자의 기기에만 있습니다.

## 수집 워크플로

`.github/workflows/feed.yml`(공고 수집)이 이 저장소의 GitHub Actions에서 피드를 만듭니다. 이 파일은 비공개 저장소의 같은 워크플로를 그대로 옮긴 사본이고, 수집기 코드는 실행할 때 비공개 저장소에서 받습니다(`.github/collector-pin`이 그 판). 여기서 직접 고치지 않습니다.

- 실행 로그에는 숫자(끝 코드·줄 수)만 남기고, 공고 제목·본문·첨부 이름·연락처는 찍지 않습니다. 같은 실행 안에서 로그를 다시 훑어 그런 글이 있으면 실패로 끝납니다. 로그 보존은 3일입니다.
- 트리거는 예약 실행과 손 실행뿐입니다(풀 리퀘스트로는 돌지 않습니다).
- 수집 규칙(robots.txt·수집기 이름 JanghakMonitor·요청 간격·하루 횟수)은 비공개 때와 같습니다.

`main` 가지에는 안내문과 워크플로만 있습니다. 피드 파일·서명은 `gh-pages` 가지에서 자동으로만 바뀌니 손으로 고치지 마세요.
