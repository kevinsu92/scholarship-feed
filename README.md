
# scholarship-feed — 내 장학 마감표 공고 피드

「내 장학 마감표」(웹 [jangmak.com](https://jangmak.com) · iOS 앱)가 받는 **장학 공고 피드를 정적 파일로 내보내는 공개 통로**입니다. 운영자는 함동수입니다.

> **이 저장소는 피드 전용입니다.** 수집기·앱·웹의 코드는 비공개 저장소에 있고, 여기에는 안내문과 워크플로 사본, 그리고 `gh-pages` 가지의 피드 파일만 있습니다.

## 여기 무엇이 있나

| 위치 | 내용 |
|---|---|
| `gh-pages` 가지 | 서명한 피드 파일. 자동으로만 바뀝니다(손으로 고치지 마세요) |
| `main` 가지 | 이 안내문 · `.github/workflows/`의 워크플로 사본 · `.github/collector-pin`(쓰는 수집기 판) · `collector/scripts`(수집기 시험용 스크립트) |

- **피드 주소:** <https://kevinsu92.github.io/scholarship-feed/v2/index.json> (목차) + 전국·시·도 묶음
- 웹과 앱은 **서명을 확인한 피드만** 씁니다.

## 어떻게 만들어지나

1. 수집기가 하루 세 번 각 기관이 공개한 원문(대학·재단·지자체·공공기관 게시판)을 모읍니다. robots.txt를 지키고, 로그인·차단 우회는 하지 않습니다.
2. 자격·마감·서류를 구조화하고 판정 근거가 된 짧은 문장을 붙인 뒤 Ed25519로 서명합니다.
3. `gh-pages` 가지를 통째로 새로 올립니다(이력 없이 덮어쓰고, 지난 회차 묶음은 한 번 더 남깁니다).

피드는 공고를 요약·구조화한 값과 짧은 근거 문장만 담고, 원문과 첨부는 출처 링크로 잇습니다. 남의 휴대폰 번호·개인 메일은 가려서 싣습니다. 지원 가능 여부의 최종 확인은 원문에서 해 주세요.

## 개인정보

이 저장소에는 학생 정보가 없습니다. 학생의 프로필(성적·소득분위 등)은 각자의 기기에만 있고 어디로도 보내지 않습니다.

## 수집 워크플로

`.github/workflows/feed.yml`(공고 수집)이 이 저장소의 GitHub Actions에서 피드를 만듭니다. 비공개 저장소의 같은 워크플로를 그대로 옮긴 사본이고, 수집기 코드는 실행할 때 비공개 저장소에서 받습니다(`.github/collector-pin`이 그 판). 여기서 직접 고치지 않습니다.

- 실행 로그에는 숫자(끝 코드·줄 수)만 남기고, 공고 제목·본문·첨부 이름·연락처는 찍지 않습니다. 같은 실행 안에서 로그를 다시 훑어 그런 글이 있으면 실패로 끝납니다. 로그 보존은 3일입니다.
- 트리거는 예약 실행과 손 실행뿐입니다(풀 리퀘스트로는 돌지 않습니다).
- 수집 규칙(robots.txt·수집기 이름 JanghakMonitor·요청 간격·하루 횟수)은 비공개 때와 같습니다.
